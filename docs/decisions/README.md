## Template for future ADRs
```markdown
# ADR-XXX — Title
- Status:
- Date:
- Context:
- Decision:
- Alternatives:
- Consequences:
- Verification / follow-up:
```

An ADR records **why** a decision was made; it does not prove a resource was deployed. Update status rather than silently rewriting historical rationale.
